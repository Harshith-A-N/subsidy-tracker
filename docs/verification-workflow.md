# Multi-Level Verification Workflow

## Overview

Once an application passes eligibility validation, it is forwarded through multiple approval stages.

## Workflow

Beneficiary
    ↓
Application Submitted
    ↓
Eligibility Verification
    ↓
Field Officer Verification
    ↓
District Officer Approval
    ↓
Finance Officer Approval
    ↓
Ready for Disbursement

---

## Field Officer

Responsibilities:

- Verify beneficiary information
- Perform physical verification
- Validate uploaded documents
- Add verification remarks
- Approve or Reject application
- Request re-verification if required

---

## District Officer

Responsibilities:

- Review Field Officer report
- Approve or Reject application
- Escalate exceptional cases

---

## Finance Officer

Responsibilities:

- Verify budget availability
- Approve fund release
- Initiate disbursement process

---

## Re-verification

If additional documents or corrections are required:

Application
    ↓
Returned to Beneficiary
    ↓
Beneficiary Updates Information
    ↓
Application Resubmitted
    ↓
Verification Restarts
